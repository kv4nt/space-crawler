# Эталонные картинки для редактора

## `example_astronaut_pixel.png` — идеальный формат

- **32×32 px** pixel-art
- **Flat colors** — без градиентов и сглаживания
- **Прозрачный фон** — космос в игре будет чёрным
- **6–8 цветов** — контур, белый скафандр, синий визор, оранжевые акценты
- **Крупный силуэт** — персонаж занимает ~80% холста

Нажмите «Загрузить эталонный пример» в редакторе или перетащите этот файл.

## Что НЕ подходит

| Плохо | Почему |
|-------|--------|
| JPEG с белым фоном | фон заливает сетку |
| Градиентные иллюстрации | сотни оттенков → шум на 40×40 |
| Мелкие детали | теряются при масштабе |
| Anti-aliased edges | размытые полупиксели |

## Как готовить свои картинки

1. Рисуйте в Aseprite / Piskel / Photoshop (режим Pencil, без blur)
2. Экспорт **PNG** с прозрачностью
3. Размер **32–64 px** по большей стороне
4. В редакторе: **6–10 цветов** в настройке упрощения
