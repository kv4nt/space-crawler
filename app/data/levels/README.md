# Уровни — pixel-art

## Редактор уровней (рекомендуется)

Веб-инструмент для конвертации PNG в готовые файлы уровня:

```bash
./scripts/run-level-editor.sh
# или: docker build -t space-crawler-level-editor tools/level-editor && docker run --rm -p 8080:8080 space-crawler-level-editor
```

Откройте http://localhost:8080 — загрузите картинку, задайте ID и название, скачайте ZIP.

**Скопируйте в эту папку:**
- `level_XXX.json` — обязательно (паттерн + палитра)
- `level_XXX.png` — опционально (исходник для справки)

Превью `level_XXX_preview.png` в игру не нужно.

### Формат JSON

```json
{
  "schema_version": 1,
  "id": 25,
  "theme_name": "Космонавт",
  "pattern": ["..22..", ".2222."],
  "color_palette": [5, 6, 2, 8, 3]
}
```

- `.` — пустая клетка (космос)
- Цифры в `pattern` — **уровень палитры** (0, 1, 2…)
- `color_palette` — индексы минералов для каждого уровня палитры

| Индекс | Цвет |
|--------|------|
| 0 | Красный |
| 1 | Зелёный |
| 2 | Синий |
| 3 | Жёлтый |
| 4 | Салатовый |
| 5 | Чёрный |
| 6 | Белый |
| 7 | Коричневый |
| 8 | Оранжевый |
| 9 | Фиолетовый |
| 10 | Серебро |
| 11 | Серый |
| 12 | Тёмно-серый |
| 13 | Голубой |
| 14 | Розовый |
| 15 | Бордовый |
| 16 | Золотой |
| 17 | Мятный |
| 18 | Бежевый |
| 19 | Индиго |

Символы `a`–`j` в pattern = уровни палитры 10–19.

Игра загружает JSON через `AuthoredLevelPack.gd`. Пользовательские уровни расширяют пул поверх встроенных 24 уровней из `PixelArtLevels.gd`.

## Авторские уровни (встроенные)

24 детальных pixel-art уровня в `PixelArtLevels.gd`. Цикл: 1→Космонавт … 24→Орбита, 25→следующий в пуле (JSON или снова 1).

## PNG-пул (резервный)

Если ни JSON, ни встроенный уровень недоступны — используются PNG `level_001.png` … `level_010.png`.

**Советы для PNG:**
- Любой размер — масштабируется до 40×40
- Прозрачный фон = пустой космос
- Яркие цвета → цвета минералов
