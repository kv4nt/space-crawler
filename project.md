# Starvein: Frontier Protocol — Project Log

> **Статус:** Food Hunt механика + жизни и бустеры за CR, 5 уровней.
> **Стек:** Godot 4.x Stable, GDScript, 2D. Portrait Android/iOS only.
> **Референс-механика:** color-sort puzzle (Food Hunt–style), но оригинальный sci-fi сеттинг.

## Оригинальность

Starvein — оригинальная sci-fi головоломка: автономные добывающие корабли собирают минералы в многослойных астероидах на фоне звёзд и планет. Используется лишь общая жанровая механика цветов, слотов и слоёв. **Нельзя** копировать названия, UI, арт, уровни, тексты, звук и код других игр.

## Core loop (Food Hunt)

1. Pixel-art карта астероида сверху — цветные блоки, скрытые внутри (`?`).
2. **Стопки цветов** снизу — игрок нажимает стопку → флот занимает **слот**.
3. Флот автоматически **поедает** доступные пиксели своего цвета (умножение: один укус → каскад).
4. Слот **блокируется** (⏸), если цвет есть, но спрятан внутри — нужно сначала открыть слой.
5. Слот **освобождается**, когда все пиксели этого цвета съедены.
6. **Победа:** последний пиксель удалён с поля.
7. **Поражение:** все слоты заняты и заблокированы — теряется 1 жизнь (макс. 5).
8. **Warp ×2** — ускорение поедания.
9. **Бустеры за CR:** подсказка, снятие блока слота, сканер, импульс.
10. **Жизни:** покупка +1 за 150 CR при поражении или в меню (на уровне).

## Архитектура

```
app/
├── scenes/
│   ├── app/Main.tscn          # Главное меню
│   ├── gameplay/Level.tscn    # Игровой уровень
│   └── ui/SpaceBackground.tscn
├── scripts/
│   ├── autoload/
│   │   ├── GameBalance.gd     # Константы баланса и уровни
│   │   ├── GameState.gd       # Runtime: кредиты, warp, текущий уровень
│   │   ├── SaveService.gd     # user://savegame.json
│   │   ├── AudioService.gd    # Music/SFX шины, процедурный звук
│   │   └── LevelService.gd    # Загрузка уровней
│   ├── gameplay/
│   │   ├── AsteroidGrid.gd    # Pixel-art поле, exposure, поедание
│   │   ├── GridCell.gd        # HIDDEN → EXPOSED → EMPTY
│   │   ├── SlotManager.gd     # Слоты флота + каскадное поедание
│   │   └── LevelController.gd # UI + визуал + связка
│   └── menu/MainMenu.gd
└── data/levels/               # JSON уровней (этап 4+)
```

## Автозагрузки

| Имя | Назначение |
|-----|-----------|
| GameBalance | Размер сетки, цвета, квоты, параметры warp |
| GameState | credits, lives, current_level, warp_core_seconds_left |
| SaveService | Атомарное сохранение/загрузка |
| AudioService | play_sfx, play_music, громкость |
| LevelService | load_level(id) → Dictionary |

## Состояния клетки

| State | Цвет виден? | Можно съесть? |
|-------|-------------|---------------|
| HIDDEN | Нет (тёмный блок) | Нет |
| EXPOSED | Да | Да (если цвет разблокирован и есть слот) |
| EMPTY | Нет (пусто) | — |

Новый цвет открывается после съедения ~35% пикселей поля.

## Warp Core

- При первом запуске: 5 мин бесплатно (`WARP_CORE_FREE_MINUTES`).
- Активен: ускорение поедания ×2 (`WARP_CORE_SPEED_MULTIPLIER`).
- После истечения: покупка за `WARP_CORE_COST_CREDITS` (300).
- Сохраняется в savegame.json.

## Проверка

1. Запустить проект (F5) → главное меню.
2. «НАЧАТЬ ИГРУ» → уровень 1, pixel-art карта, 2 цвета, 3 слота.
3. Нажать стопку цвета → флот занимает слот и начинает поедание.
4. Съесть ~35% → открывается следующий цвет.
5. Warp Core → ускорение ×2, таймер в HUD.
6. Победа: все пиксели съедены. Поражение: все слоты заблокированы.
7. Перезапуск сохраняет кредиты и warp-статус.
